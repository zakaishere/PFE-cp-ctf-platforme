Validate Stack Sequence

Worth: 25 pts Time limit: 1000 ms Memory: 256 MB

Given two integer sequences pushed and popped, each a permutation of the same elements, determine whether popped could be the result of a sequence of push and pop operations on an initially empty stack, using pushed as the push order.

Print YES if the sequence is valid, otherwise NO.

Input

Line 1: n (1 ≤ n ≤ 10⁵). Line 2: the pushed sequence. Line 3: the popped sequence.

Example

Input
5
1 2 3 4 5
4 5 3 2 1
Output
YES
