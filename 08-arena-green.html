C. Balanced Subarrays
Medium Time: 1000 ms Memory: 256 MB 300 pts

You are given an array of n integers. A subarray is called balanced if the number of even elements equals the number of odd elements inside it.

Count how many non-empty subarrays are balanced. Two subarrays are different if their start or end index differs.

Input

The first line contains an integer n (1 ≤ n ≤ 2·10⁵).
The second line contains n integers a₁ … aₙ (1 ≤ aᵢ ≤ 10⁹).

Output

Print a single integer — the number of balanced subarrays.

Example

Input
4
1 2 3 4
Output
4
Solution
C++ 17
1234 5678 91011
// prefix balance trick #include <bits/stdc++.h> using namespace std; int main(){ int n; cin >> n; long long ans=0, bal=0; map<ll,ll> cnt; cnt[0]=1; for(int i=0;i<n;i++){ ll x; cin>>x; bal+=(x&1)?1:-1; ans+=cnt[bal]++;} cout<<ans;}
