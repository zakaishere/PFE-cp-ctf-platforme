Problems / C — Balanced Subarrays
C.

Balanced Subarrays

MediumTime: 1000 msMemory: 256 MB300 pts

You are given an array of n integers. A subarray is called balanced if the number of even elements equals the number of odd elements. Count how many non-empty subarrays are balanced.

Input

Line 1: n (1 ≤ n ≤ 2·10⁵). Line 2: n integers.

Output

A single integer — the number of balanced subarrays.

Example

Input
4
1 2 3 4
Output
4
Solution
C++ 17 ▾
12345678910
// prefix balance trick #include <bits/stdc++.h> using namespace std; int main(){ int n; cin >> n; long long ans=0, bal=0; map<ll,ll> cnt; cnt[0]=1; for(int i=0;i<n;i++){ ll x; cin>>x; bal+=(x&1)?1:-1; ans+=cnt[bal]++; } cout<<ans; }
